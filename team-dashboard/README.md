# NEXUS — локальный командный центр

Интерфейс читает общую память проекта из `knowledge/` и `operations/`, показывает состояние команды, контент-календаря и аналитики. Чат вызывает локально установленный Codex и выбранный skill в безопасном режиме `read-only`.

## Запуск

```bash
/Users/dmitrij/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node team-dashboard/server.mjs
```

Открыть: <http://127.0.0.1:4173>

## Границы первой версии

- Чат читает память, но не изменяет проект без отдельного подтверждённого рабочего процесса. Перед первым сообщением интерфейс отдельно предупреждает, что сообщение и релевантный контекст будут обработаны облачным сервисом Codex.
- Календарь и аналитика показывают реальные данные из Markdown-файлов, поэтому пустые разделы остаются честно пустыми.
- История сообщений интерфейса хранится локально в браузере.
