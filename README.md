# Social Growth Team

Готовая AI-команда для системного продвижения экспертного проекта через социальные сети: от исследования аудитории и позиционирования до контент-плана, производства материалов и анализа результатов.

## Что внутри

- `social-producer` — единая точка входа и оркестратор команды;
- исследователь аудитории, маркетинговый и SMM-стратеги;
- авторы постов, Stories и Reels;
- визуальный продюсер и независимый Brand Guardian;
- общая база знаний в `knowledge/`;
- рабочие процессы и журналы в `operations/`;
- локальная панель NEXUS в `team-dashboard/`;
- сценарии проверки и оценочная карта в `tests/`.

## Установка

```bash
git clone https://github.com/bymaksimenko-stack/social-growth-team.git
cd social-growth-team
```

Откройте папку проекта в Codex. Локальные навыки команды находятся в `.agents/skills/` и будут доступны в контексте проекта.

## Первый запуск

Откройте новый чат в проекте и напишите:

> Используй `social-producer`. Начни моё первичное интервью для создания бренд-брифа. Задавай вопросы короткими блоками, фиксируй выводы и не переходи к стратегии, пока я не утвержу бриф.

Подробная инструкция: [START_HERE.md](START_HERE.md).

## Локальная панель NEXUS

Для панели нужен Node.js. Из корня проекта выполните:

```bash
node team-dashboard/server.mjs
```

Затем откройте <http://127.0.0.1:4173>.

## Принцип работы

Команда строит проверяемую систему:

`исследование → позиционирование → контентная воронка → материалы → утверждение человеком → результаты → улучшение`

Стратегия и материалы не получают статус `approved` без явного решения пользователя. Внешняя публикация и генерация изображений также запускаются только по отдельному запросу.

## Проверка структуры

```bash
python3 scripts/validate_team.py
```
